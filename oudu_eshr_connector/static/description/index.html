概述

Odoo金蝶e-sHR集成模块是一个企业级的人力资源系统集成解决方案，实现金蝶e-sHR与Odoo系统之间的组织架构、员工信息的实时同步。该模块通过自动化的数据同步机制，确保两个系统之间数据的一致性和准确性。

特别适用于使用金蝶e-sHR作为主人力资源管理系统，同时使用Odoo进行业务管理的企业。通过本模块，企业可以避免数据重复录入，提高数据准确性，降低人工维护成本。

实时数据同步

支持定时自动同步，确保金蝶e-sHR与Odoo系统数据的实时一致性，减少人工干预

组织架构同步

完整同步部门层级结构、职位信息，保持组织架构在两个系统中的一致性

员工信息同步

自动同步员工基本信息、岗位、上级关系、联系方式等关键人力资源数据

双向数据映射

建立金蝶e-sHR与Odoo系统间的数据映射关系，支持字段级别的数据转换

数据安全可靠

采用安全的数据库连接方式，确保数据传输安全，支持错误重试机制

灵活配置

支持同步频率自定义、字段映射配置、同步日志查看等灵活配置选项

系统集成架构

🔹 数据源层: 金蝶e-sHR SQL Server数据库

🔹 集成中间件: Odoo同步服务 + 数据映射引擎

🔹 目标系统层: Odoo HR模块（部门、员工、职位）

🔹 监控管理层: 同步日志、错误处理、性能监控

同步数据范围

🔹 部门组织架构、员工基本信息、职位岗位信息、上下级关系、联系方式、入职信息
