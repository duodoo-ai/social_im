概述

这套餐厅连锁企业提供的采购管理解决方案，特别强调移动办公和微信集成的便利性。

集成了微信服务号，用户可以通过扫描二维码或通过服务号授权快速登录Odoo系统，并实现采购订单的创建、管理和跟踪。

采购管理核心功能

采购订单管理：完整的餐厅采购流程（草稿→主厨提交→采购中→已收货→完成）

多门店支持：支持多个餐厅门店的独立采购管理

角色分工：主厨下单、采购员采购、收货人收货的权限分离

微信集成功能

消息推送：采购订单状态变更时自动发送微信通知

消息跳转：微信消息可直接跳转到系统相关页面（采购订单详情、商品库管理等）

用户认证：支持微信用户自动登录和权限验证

点击统计：记录消息点击率和用户行为数据

工作台与界面功能

采购工作台：集中展示今日订单、待收货统计等信息

实时统计：动态计算采购进度和金额统计（移动端支持）

商品与数据管理

商品库管理：预置餐厅常用商品（米、油、蔬菜、肉类、海鲜、调味品等）

单位管理：支持公斤、升等不同计量单位（移动端支持）

价格管理：记录商品标准价格和采购价格（移动端支持）

移动端优化

响应式设计：适配手机和平板设备（移动端支持）

快速操作：针对移动场景优化的快速收货、状态切换等功能（移动端支持）
